# Module Courses — panier de drive préparé par l'assistant

Module privé construit sur SophIA : à partir d'une liste de courses (celle du [module Cuisine](../cuisine/README.md), une saisie libre, des courses récurrentes), il **choisit les produits** d'un drive alimentaire selon les règles du foyer et **remplit le vrai panier**. Le créneau et le paiement restent toujours à l'humain, dans l'application de l'enseigne.

| | |
|---|---|
| État | en service dans l'installation de référence ; quelques correctifs en recette ; pas encore affiché dans le cockpit de l'interface (ouvert à part) |
| Utilisateurs | les adultes du foyer (seuls autorisés à écrire) ; aucun compte enfant |
| Forme | un moteur exposé en **MCP** (module Cuisine, discussion), une page web de secours, un navigateur distant dans le sas |
| Modèle | `sophia-local`, pour **comprendre** une ligne de liste — jamais pour choisir un produit |
| Code | privé ; cette page décrit l'architecture et les règles |

Documentation détaillée : [documentation.md](documentation.md). Autres modules : [modules privés](../README.md).
